# Ikigai Finder

A small, responsive website exploring the four Ikigai questions:
- What do you love to do?
- What are you good at?
- What could you be paid for?
- What does the world need?

## Run locally

Open `index.html` in a browser. No build tools are required for the current frontend.

## Current status

The first page and form validation are in place. All systems are online.

## Project structure

- `index.html` — page structure and form
- `style.css` — layout, colors, responsive design
- `careers.js` — Database
- `analyser.js` — Matching system
- `script.js` — Ikigai recommendations by default
